# 智能简历构建器

一款纯前端智能简历构建器，支持本地多版本简历管理、模块化编辑、模板切换、A4 预览和 PDF 导出。

## 功能列表

- 简历列表：创建、复制、删除多份简历版本。
- 简历编辑器：左侧模块拖拽排序，中间结构化编辑，右侧实时预览。
- 模板选择：内置 6 套简历模板，可应用到当前简历并作为新建默认模板。
- PDF 导出预览：A4 比例预览，支持页边距、字号调整和 PDF 导出。
- 个人资料：维护姓名、联系方式、头像、求职意向等全局资料。
- 本地持久化：简历、个人资料、主题偏好和模板偏好存储在 localStorage。
- JSON 导入导出：支持完整工作区备份和恢复。
- 只读分享台：为简历生成**不依赖服务端**的快照链接，见下文。
- 主题切换：亮色/暗色主题，所有组件通过 CSS 变量消费主题色。

## 只读分享台（无服务端快照链接）

在简历卡片或卡片菜单中点击「分享」，选择模块并固定顺序后即可生成只读链接。

- **快照自包含**：链接形如 `http://<站点>/#share/<token>`，简历内容经 deflate-raw 压缩后整体内嵌在 URL hash 中，打开时不请求任何服务端，浏览器也不会把 hash 发送出去。
- **固定模块范围与顺序**：生成时勾选的模块及其顺序被写入快照，查看页严格按此渲染。
- **源简历变化不影响旧链接**：每次生成都深拷贝当时内容；事后修改简历不会改写任何旧链接，只有重新生成才会产生新快照。
- **多份互不覆盖**：同一简历可生成任意多条分享记录，每条独立。
- **撤销是本机操作**：在「分享」页撤销一条记录只删除本机索引；其他记录不受影响，已经发出的旧链接（快照自包含）仍然可打开。
- **明确失败、不污染本机**：损坏、旧版本（非 v1）、被改写（SHA-256 校验不符）或超过 16000 字符的链接会显示明确的中文错误页，解析过程不读取或修改任何本机简历。
- **刷新与备份可核对**：分享记录持久化在 localStorage（`smart-resume:share-records:v1`），进入「分享」页会逐条重新解码并与记录摘要核对；JSON 备份/恢复会带上分享记录，恢复时损坏条目被跳过并提示。

分享链接打开的是独立只读查看页（不加载工作台导航与本机数据），底部标注生成时间与固定模块顺序。

## 快速启动

```bash
cd frontend
npm install
npm run dev
```

开发服务器端口固定为 `28310`：

```text
http://localhost:28310
```

构建与预览：

```bash
npm run build
npm run preview
```

## 技术栈

| 分类 | 技术 |
| --- | --- |
| 前端框架 | React 18 + TypeScript |
| 构建工具 | Vite |
| 样式 | Tailwind CSS + SCSS CSS Variables |
| 无障碍交互 | Headless UI |
| 状态管理 | Zustand |
| 拖拽排序 | react-beautiful-dnd |
| PDF 导出 | html2canvas + jsPDF |
| 日期工具 | dayjs |
| 数据持久化 | localStorage |
